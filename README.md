# VAPE HOUSE - Premium Vape Store Website

A modern, responsive e-commerce web application for Vape House featuring a dark futuristic theme with purple and neon-green accents.

## Features
- **Homepage**: Hero showcase with ambient lighting, category cards, promotional showcase banners, trending carousel, and brand trust badges.
- **Collections Page (`/collections`)**: Complete interactive catalog with live sidebar filtering (categories, brands, price range, flavor tags), sorting, grid/list view toggling, and pagination.
- **Product Details Page (`/products/:slug`)**: Dynamic product pages with interactive multi-image thumbnail gallery, color swatches, quantity stepper, accessible toast notifications, tabbed specifications, related products, and recently viewed products.
- **Clean Node Routing**: Built-in HTTP server (`server.js`) supporting direct URL navigation and browser refreshes for all routes.

## Quick Start
```bash
# Run development server
npm run dev
```
